# Actual English conversation evidence

These five conversations were executed on November 1, 2026 using local Ollama
and qwen3:4b-instruct. Questions were scripted for evaluation; tool calls and
answers were produced by the real model/application. They are **not mocked tests**.

Only approved public synthetic fixtures were loaded. The eleven-day synthetic
return reference is deliberately different from the private store manual. No
original customer record, contact detail, or restricted source policy is included.
Product names remain source labels in Portuguese; the dialogue is in English.

| Conversation | Observed outcome |
| --- | --- |
| [Catalog and promotion](01-catalog-and-promotion.md) | Two available products, ascending prices; PIX quote 90.09 with no stacked discount |
| [Unavailable product](02-unavailable-product.md) | Product 2 unavailable; two available alternatives |
| [Policy and missing evidence](03-policy-and-missing-evidence.md) | Synthetic eleven-day reference retrieved; missing refund deadline/action not invented |
| [Authorized order](04-authorized-order.md) | Recorded total 99.00 preserved; tracking/actual delivery remain unknown |
| [Denied order](05-denied-order.md) | Uniform denial; conversational identity change refused |

All ten turns completed with status answered. This is a small observed sample,
not a statistical accuracy score. The policy follow-up is factually conservative
but still mentions internal evidence labels; its unedited wording is retained as
a presentation limitation, not silently polished. Generic model prose may also
be verbose. There was no request to initiate a real transaction.

`live-conversations.json` contains timestamps, runtime commit, model/fixture
digests, model parameters, actual requested/effective arguments, minimized tool
results, and verbatim customer-visible answers. Each turn labels its answer as
live-model prose or application-guard wording after real inference. Deterministic
guards are not misrepresented as text generated by the LLM.

To capture another **actual** synthetic-only run after installing the project:

```powershell
.\.venv\Scripts\python.exe scripts/capture_examples.py --model qwen3:4b-instruct --output examples/new-run
```

Use another output directory to preserve these historical examples. The model
must already exist locally and support tools; this local instruct tag is not
assumed to be downloadable from the public registry. The public qwen3:4b tag is
an alternative, with different parameters/template. Runtime code must be
committed before capture so its revision can be recorded accurately. Sampling
is not fixed, so wording and tool-call sequences can vary on a new run.
